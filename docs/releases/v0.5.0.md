# Huawei VR Glass ALVR v0.5.0

本版本完善 Huawei 6DoF Gaming Kit 摇杆输入，并把 PC 新会话默认视频配置改为跟随头显 Runtime 推荐视图。

## 主要变化

- Huawei 摇杆从厂商 Runtime 的 0～1、中心 0.5 范围归一化到 SteamVR 使用的 -1～1。
- 修正摇杆 Y 方向，加入半径 0.12 的圆形死区；任一轴变化时成对发送 X/Y，避免死区重映射造成另一轴残留。
- “编解码单眼分辨率”和“模拟头显单眼分辨率”默认均改为 Runtime 推荐值 `1.0×`。
- 当前 Huawei VR Glass 上报 1552×1552/眼，经 ALVR 32 像素对齐后实际协商为 1536×1536/眼。
- PC 首选帧率设为 72 Hz；Huawei Runtime 当前只提供 70 Hz，因此真机会话仍自动选择最接近的 70 Hz。
- 根 README 改为华为专版完整中文入口，并补充手机、VR、Dashboard 和 Launcher 截图、安装说明、参数与排错信息。
